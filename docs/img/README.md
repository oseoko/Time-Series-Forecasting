# 리포트 캡처

`analysis/fs_report_sig2.html`(sig2 + ±20% 실행분)에서 뜬 캡처다.

| 파일 | 리포트 섹션 | 쓰이는 곳 |
|---|---|---|
| `weekly.png` | 주별 전망과 근거 (6/1~6/7) | README 최상단 |
| `heatmap.png` | 판정은 날짜 단위로 이뤄진다 (요인 × 7일) | README "어떻게 작동하나" |
| `kpi.png` | 요약 (KPI 4칸) | RESULTS 최상단 |
| `drivers.png` | 수요를 움직이는 것 (확인된 요인) | RESULTS 채널 선별 문단 |

리포트를 다시 생성하면 수치가 바뀔 수 있으니, 문서의 숫자와 어긋나면 같은 섹션을 다시 캡처한다.
